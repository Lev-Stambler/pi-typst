# Provenance of `cetz-api.md`

`cetz-api.md` was written for pi-typst. It condenses **factual** API
information — function names, argument lists, default values, anchor and style
key names, and short behavioural notes — from:

- **CeTZ 0.5.2**, © the CeTZ authors, licensed
  [LGPL-3.0-or-later](https://github.com/cetz-package/cetz/blob/main/LICENSE),
  repository <https://github.com/cetz-package/cetz>, and
- the CeTZ manual/online documentation at <https://cetz-package.github.io/docs>.

No prose, documentation text, or source code from CeTZ is copied into this
directory; the descriptions are independently written. CeTZ is not redistributed
with pi-typst — Typst resolves `@preview/cetz:0.5.2` from the package registry
at compile time, and the upstream license applies to that copy.

If you plan to redistribute a modified CeTZ itself, follow the upstream LGPL
terms instead of this notice.
